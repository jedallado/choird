# Choird documentation

Choird is a choir songbook. Leaders maintain songs and scheduled set lists in an admin panel. Singers browse that catalog in a mobile app that works offline after a sync.

- [Features](features.md) — what the product does today
- [Architecture](architecture.md) — how the mobile app, API, and admin panel fit together
